# Pipeline Scripts

Main scripts for video-to-3DGS pipeline.

## Scripts

- `automated_intelligent_pipeline.py` - Full intelligent pipeline with chunking
- `enhanced_video_to_colmap.py` - Enhanced COLMAP processing
- `video_to_colmap.py` - Basic video to COLMAP
- `images_to_colmap.py` - Images to COLMAP
